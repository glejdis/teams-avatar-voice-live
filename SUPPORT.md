# Support

Thanks for using **Teams Avatar Voice Live**! 👋 This page explains where to get
help and what to expect.

> **ℹ️ This is an independent, community project — not an official Microsoft
> product** and not covered by Microsoft support plans. See
> [DISCLAIMER.md](DISCLAIMER.md).

## How to file issues and get help

This project uses **GitHub Issues** to track bugs and feature requests. Please
search [existing issues](https://github.com/glejdis/teams-avatar-voice-live/issues)
before opening a new one to avoid duplicates.

- 🐛 **Found a bug?** Open a [Bug report](https://github.com/glejdis/teams-avatar-voice-live/issues/new/choose).
- 🤖 **Want a new persona / agent?** Use the *Agent request* issue template.
- 💬 **Have a question or idea?** Start a
  [Discussion](https://github.com/glejdis/teams-avatar-voice-live/discussions)
  (or open an issue if Discussions aren't enabled).
- 📖 **Getting started?** Read the [README](README.md) —
  the [Quickstart](README.md#quickstart) and the browser
  [30-second smoke test](README.md#30-second-smoke-test-the-browser-path) are the
  fastest paths. Deeper docs live in [`docs/`](docs/), including
  [`docs/RUNBOOK.md`](docs/RUNBOOK.md) for day-2 operations and troubleshooting.

When reporting a problem, please include:

- what you expected vs. what happened,
- the transport you're using (`graph_bot` or `browser_webrtc`),
- relevant logs or error messages **with all secrets, tokens, tenant IDs,
  meeting URLs, and PII redacted**.

## Security issues

**Do not** report security vulnerabilities through public issues. Please follow
[SECURITY.md](SECURITY.md) instead.

## Support policy

This project is maintained on a **best-effort, volunteer basis**. There is no
guaranteed response time or SLA. Issues in the underlying Microsoft services
(Azure, Microsoft Teams, Microsoft Graph, Azure AI Foundry, Azure Voice Live)
should go to Microsoft support / [MSRC](https://msrc.microsoft.com/), not here —
report to this project only issues in *this repository's* code and configuration.
